- comment faire des rotations de clé (dont la clé de signature) - tiering PKI
    - Modele 3 tiers :
        - T0 - root : 15-20ans local only
        - T1 - CA of CA : 5-10ans signe les CA
        - T2 - Leaf : 24h-90jrs signature automatisée pour serveurs, users,...
    - rotation de clé : Reissue (a eviter) our Renew (chevauchement comme enoncé au dernier point)
        - generer nouvelle clé
        - publier 2 CA sur les machines
        - basculer sur la nouvelle clé sans enlever l'ancienne
        - apres drainage complet retirer l'ancienne clé 
    - Tiering ssh pas possible donc les tiers se font par role plutot que par niveau (une clé pour les serveurs, une pour les users par ex.)
    
- recherches sur ssl, les modes de chiffrement entre ssh et https et la difference entre sftp et ftps
    - protocole SSL est interdit. le mot persiste
    - SSH : auto suffisant, confiance symétrique
        - pas de tier a contacter
    - TLS : Ecosysteme de CA (externalisé), confiance que d'un seul coté
        - scalabilité de la confiance pour des inconnus
    - sftp vs ftps 
        - sftp : sous système de SSH, un seul port a ouvrir (22 par defaut), clé ssh
        - ftps : ftp with TLS, chiant a config pour FW : TLS empeche les redirections et plage de port vaste, certificat X.509 + mdp

- qu'est ce que le domain fronting
    - exploitation d'une incohérence HTTPS, on met un domaine innocent en SNI et le domaine malveillant dans le header http (donc chiffré dans le tunnel TLS)
        - mitigation : MITM si réseau d'entreprise mais bcp de CDN comme google l'ont désactivé 

- qu'est ce que le filtrage par SNI
    - TLS annonce le nom du serveur a joindre et le filtrage exploite ca

- ce qu'est un routeur "on-a-stick"
    - schéma rigolo : explicite; routeur relié par une seule interface a un switch et assume le routing inter VLAN. utilisé quand le routeur a des fonctions que le switch n'a pas (FW, VPN,...)

- qu'est ce que le protocole TLP (traffic light protocol)
    - marquage de la sensibilité et des règles du partage de renseignement, basé uniquement sur confiance et aucune obligation mais est reconnu a l'internationnal
