Recherches :

- comment fonctionne le protocole BGP
    - Routage inter-AS, chacun énonce ses préfixes et le routage se fait par le chemin le plus court. Pas de vérification de qui a le droit d'annoncer quoi. 

- regarder le BGP looking glass de Hurricane electric
    - Interface web de la table de routage dans le monde. Utilisé pour détecter les leak/hacks sans avoir de peering

- comment fonctionne le protocole DNS
    - obj : expliquer la fonction d'un registrar
        - identifier la racine de l'infra DNS
        - donner une analyse de risque sur DNS et une mauvaise config
        - chercher : sub domain takeover
    - Racine : 13 serveurs
    - Serveurs TLD
    - Serveur autoritaire du domaine (celui qui a payé)
    Registrar : Entité accréditée pour vendre/administrer des noms de domaine au nom du client
    Sub-domain takeover : Un service est supprimé mais le DNS non. un attaquand reprovisionne le service au meme nom et prend le controle du domaine

- ce qu'est un TLD
    label du nom de domaine (.com, .fr, ...)

- ce qu'est un DNS fowarder, resolver & round robin
    - resolver : résout en interrogeant root > TLD > autoritaire
    - forwarder : ne résout pas, transmet la requete a un resolver
    - DNS round robin : rotation d'ip sur un même requete (répartition de charge)

- ce qu'est un rootkit
    - malware discret qui tourne en root silencieusement

- regarder les modalités d'activation des démons systemd
    - `socket-enabled` lancé lors de la premiere écoute sur un socket
    - `path-activated` activer par un event dans un fichier
    - les autres je connais (enable, requires, after,...)

- lire sur OIDC (open id connect)
    - délégation d'authorité (qui peut lire quoi)

- AuthN vs AuthZ
    - authentication (qui)
    - authorization (quel droits)

- ce qu'est MTLS
    - mutual TLS, un certificat X509 de chaque coté

- ce qu'est SSL Bumping & la DPI (deep packet inspection)
    - SSLBumping : FW fait MITM et inspecte les TLS
    - DPI : Analyse de plus que les headers (signatures, pattern matching,...)

- ce qu'est VLAN tagging
    - tag 802.1Q dans la trame ethernet pour faire tout transiter par le meme lien physique

- tunnel ssh et reverse tunnel ssh
    - ouvre un port distant et le redirige par le tunnel

- config ssh : que faire pour interdire à un utilisateur la mise en place de tunnel sans restreindre le cli
    - `AllowTcpForwarding` (et `PermitOpen` pour restreindre a certains ports)

- risque géopolitique d'utilisation d'outil open source dans un pays hostile
    - risque de backdoor imposé par l´ état; rétention de patch de sécurité; risque de conformité (export control)

- ce qu'est HARTBLEED
    - CVE dans une extension TLS qui permet de lire plus de données qu'annoncé dans un process

- comment gérer les secrets de connection en BDD a grande echelle avec rotation fréquente
    - solutions comme Vault ou Cloud Secrets Manager
        credentials dynamiques avec TTL

- ce qu'est TXID dans postgresql et comment restaurer a une TXID specifique (+utilité)
    - Chaque transaction a un XID pour restaurer.
    - Utilité : annuler une transaction malveillante sans perdre trop de données avant

- ce qu'est la méthodologie de collecte de métrique : chercher RED et USE
    - RED : rate error duration
    - USE : utilizaton, saturation, error
    - Deux méthodologies de monitoring
